# Automated Sales Reporting with n8n

## Project Overview
This project demonstrates how workflow automation can simplify sales and expense reporting using n8n and sample e-commerce data.

## Business Problem
Collecting sales data from multiple platforms and preparing reports manually can be repetitive and time-consuming.

## Project Goals
- Process sales and expense records.
- Calculate total revenue and expenses.
- Estimate profit.
- Prepare structured reporting output.
- Explore how n8n can reduce repetitive reporting tasks.

## Tools
- n8n
- CSV sample data
- JavaScript for data processing

## Sample Results
Using the included sample data, the expected totals are:

- Records processed: 5
- Units sold: 15
- Total revenue: $449.85
- Total expenses: $125.00
- Estimated profit: $324.85

## Current Status
Portfolio project in development. The next stage is to implement and test the workflow in n8n.

## Future Improvements
- Integrate Google Sheets.
- Add scheduled execution.
- Generate automated report summaries.
- Add validation for missing or duplicate records.

**Note:** This project uses fictional sample data. No real business accounts are connected, and time savings have not yet been measured.
